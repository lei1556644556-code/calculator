使用教程

网页使用

  1. 先选择储罐：V0204 为 1#苯储罐，V0205 为 2#苯储罐，V0206 为二甲苯储罐。
  2. 输入液位高度，默认单位为 mm，也支持 `8.500m` 这种写法。
  3. 输入 20℃密度，单位为 g/cm³。
  4. 输入罐内液体温度和罐外四周空气平均温度。
  5. 点击计算，查看实际质量、最终体积和查表修正过程。
  6. 出现红色提示时，该液位不能作为有效计量结果使用。

Excel 嵌入使用

  1. 将 `index.html` 和 `tank_data.js` 放在同一个文件夹。
  2. 在 Excel 中使用“插入 Web 页面/浏览器控件/Office 加载项”方式指向该 HTML 文件或部署后的网页地址。
  3. 如 Excel 不允许直接打开本地 HTML，建议把文件放到内网服务器，再用内网地址嵌入。
  4. 嵌入后仍按网页步骤输入参数并复制结果。

计量注意事项

  • 不同储罐使用各自的容量表和静压力修正表，切换储罐后会自动切换数据。
  • V0206：`107.00 mm（含）以下不作计量`。
  • V0206：`1437 mm - 1637 mm` 区间不得作为计量使用。
  • 容量表为 20℃容量，工具会按非保温罐公式进行温度修正。
  • V0206 液位超过 `1637 mm` 时，默认扣除浮顶影响，浮顶质量按 `3800 kg`。
  • V0204/V0205 当前工作簿未识别到浮顶质量，默认不做浮顶扣除。
  • 证书过期、罐体大修或严重变形后，应重新检定后再使用。
